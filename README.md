# colbergcpa.com — Colberg Business Solutions

Static site for Colberg Business Solutions (CCR LLC), the CPA practice of Carlos H. Colberg. Separate from Encanto Software.

- `index.html` — bilingual (ES default, EN toggle) one-page site
- `calendario-2027.html` — Puerto Rico 2027 compliance calendar (filterable)
- `404.html` — not-found page
- `styles.css` — shared styles (brand tokens at the top)
- `favicon.svg`, `favicon.png`, `apple-touch-icon.png`, `og-image.jpg` — icons and social image
- `robots.txt`, `sitemap.xml`

Deploy: Porkbun static hosting auto-deploys from `main`. Text lives in `data-es` / `data-en` attributes; edit both when changing copy.
Brand: navy #192D4D · deep navy #091830 · lime #ABCC38 · Barlow Semi Condensed + Source Sans 3.
